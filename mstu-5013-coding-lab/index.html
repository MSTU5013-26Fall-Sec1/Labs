02 / CODING

Coding is a way to think out loud.

Code is a set of instructions for a computer—but learning to code is also learning to break big ideas into small, testable steps.

{ }

Express an idea

Turn a question, process, or creative spark into something others can see, use, and respond to.

→

Give instructions

Computers are literal collaborators. Clear inputs, sequences, and rules help transform intent into action.

↻

Learn through iteration

Run it, observe it, change it. Errors are information—not a verdict on your ability.

04 / PRACTICE

Small habits make capable coders.

You do not need to memorize everything. Build a practice that helps you stay curious, test your understanding, and keep moving.

01

Make the next step smaller

If you feel stuck, shrink the task until you can try something in five minutes.

02

Read errors with curiosity

Start with the first error. Find the file and line, then translate the message into plain language.

03

Predict before you run

Say what you expect the code to do. The gap between prediction and result is where learning happens.

04

Ask for explanations

When AI suggests code, ask why it works, what could fail, and how you might test it.

05

Save working checkpoints

Commit small, meaningful changes so experimentation feels safe and your progress stays visible.

06

Teach it to someone

Explaining a concept reveals what you understand—and which question to ask next.
